# Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Features
- Semantic structure: header, nav, main, sections, footer
- Responsive at 375px, 768px and 1280px+
- Mobile nav toggle, dark/light theme toggle (saved in localStorage), project filter
- Keyboard accessible with a skip link and visible focus styles

## Tech used
HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript, Google Fonts

## Run locally
1. Clone the repo
2. Open the folder in VS Code and click "Go Live" (Live Server extension), or just open `index.html` in a browser
